# Toy Tales

A React app for managing a toy collection, connected to a json-server backend.

![Toy Tales screenshot]

## Features
- See all toys when the page loads (GET)
- Add a new toy with the form; likes start at 0 (POST)
- Like a toy to increase its likes (PATCH)
- Donate a toy to remove it (DELETE)

## Installation
npm install
npm run server # backend at http://localhost:3001
npm run dev # frontend, in a second terminal
## Usage
Click "Add a Toy" to open the form. Use the Like and Donate buttons on each card.

## Tests
npm test

## Built With
React, Vite, json-server, Vitest
